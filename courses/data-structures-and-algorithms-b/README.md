# Data Structures And Algorithms (B)

Course materials for Data Structures and Algorithms (B), 2024-2025 Spring.

## Structure

```text
lectures-syc/             Main course lecture slides
lectures-yhf-and-course/  Additional course materials
reference-lectures/       Materials from other course sections
assignments/              Coursework and submitted assignment files
practice/                 Local exercises
practice-oj/              Online judge practice
practice-leetcode/        LeetCode practice
notes-data-structures/    Data structure notes
notes-algorithms/         Algorithm notes
lab-review/               Lab exam review materials
exam-review/              Written exam review materials
```

## Large Artifacts

Binary course files such as PDF, PPT, DOCX, ZIP, and images are tracked through Git LFS.

## Excluded Local Content

The original local folder also contained items that are not suitable for version control:

- `.idea/` IDE metadata
- `.venv/` local Python virtual environment
- `*.pyc` compiled Python cache files
- `*.url` shortcut/download marker files
