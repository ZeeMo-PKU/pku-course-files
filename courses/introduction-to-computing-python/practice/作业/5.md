### 18211: 军备竞赛

greedy, two pointers, http://cs101.openjudge.cn/practice/18211

思路：
卖掉最贵的，买便宜的


代码：

```python
def army(money,b):
    mine=0
    his=0
    if b[0]>money:
        return 0
    while len(b)>1:
        if money>=b[0]:
            money-=b.pop(0)
            mine+=1
        else:
            his+=1
            money+=b.pop(-1)
    if b[0]<money:
        mine+=1
    return mine-his


money=int(input())
b=list(input().split())
b=[int(i) for i in b ]
b.sort()
print(army(money,b))
```

### 01328: Radar Installation

greedy, http://cs101.openjudge.cn/practice/01328/

思路：
太难了，感觉需要建一个数学模型


代码：

```python
import math

def solve(n, d, islands):
    if d < 0:
        return -1

    ranges = []
    for x, y in islands:
        if y > d:
            return -1
        delta = math.sqrt(d * d - y * y)
        ranges.append((x - delta, x + delta))

    if not ranges:
        return -1

    ranges.sort(key=lambda x:x[1])

    number = 1
    r = ranges[0][1]
    for start, end in ranges[1:]:
        if r < start:
            r = end
            number += 1

    return number

case_number = 0
while True:
    n, d = map(int, input().split())
    if n == 0 and d == 0:
        break

    case_number += 1
    islands = []
    for _ in range(n):
        islands.append(tuple(map(int, input().split())))

    result = solve(n, d, islands)
    print(f"Case {case_number}: {result}")
    input()
```
