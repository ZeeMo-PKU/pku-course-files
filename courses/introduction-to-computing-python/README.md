# Introduction To Computing (B) - Python

Course materials for Introduction to Computing (B), Python track, 2024-2025 Fall.

## Structure

```text
lectures/      Course slides and lecture materials
assignments/  Coursework and submitted assignment files
practice/     Programming exercises and online judge practice
exam-review/  Written exam review notes and reference materials
```

## Organization Rules

- Keep source code, notes, and submitted work in readable folders.
- Store large binary course artifacts through Git LFS.
- Exclude local IDE settings, Python runtime folders, generated bytecode, and unrelated software installers.

## Excluded Local Content

The original local folder also contained items that are not suitable for version control:

- `.idea/` IDE metadata
- `python/` local Python runtime distribution
- `计概刷过的题目/swdist/` third-party software distribution files
- `*.pyc` compiled Python cache files
- `*.url` shortcut/download marker files
