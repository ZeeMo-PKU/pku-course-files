# Excluded Files

The following source-directory content was intentionally excluded from this repository:

- Local Python runtime folder: `python/`
- IDE project metadata: `.idea/`
- SolidWorks/software distribution payloads: `计概刷过的题目/swdist/`
- Compiled Python cache: `*.pyc`, `__pycache__/`
- Shortcut marker files: `*.url`

These files are either reproducible, machine-local, too large to be useful in source control, or unrelated to the course portfolio structure.
