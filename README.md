# PKU Course Archive and Portfolio

Personal archive for university course materials, assignments, notes, practice code, review resources, and selected academic work.

The repository keeps each course on a dedicated branch so large course artifacts and course-specific folder layouts stay isolated. Curated work intended for public presentation is kept separately under [`portfolio/`](portfolio/).

## Selected Portfolio

The [`portfolio/`](portfolio/) directory contains a small, reviewed collection of reports and academic writing. It is intentionally separate from the complete course archives and includes an [academic integrity statement](portfolio/docs/academic-integrity.md).

## Repository Layout

Course branches use the `courses/<course-name>/` layout. Each course folder contains its own README with a more detailed description of the available materials.

Common folders include:

- `lectures/` or `lectures-*`: course slides and lecture materials
- `assignments/`: coursework and submitted assignment files
- `practice/`, `practice-oj/`, or `practice-leetcode/`: programming exercises and solutions
- `notes-*`: topic notes and reference implementations
- `lab-review/` and `exam-review/`: review sheets, past papers, and exam preparation resources

## Storage Notes

Large binary artifacts such as PDFs, slide decks, Word documents, ZIP archives, and images are tracked with Git LFS when needed.

Local development files, virtual environments, generated bytecode, shortcut files, and unrelated software distributions are intentionally excluded from version control.

## Usage

Switch to a course branch to view that course's materials:

```bash
git checkout 计算概论
git checkout 数据结构与算法
```

This repository combines personal study archives with a curated academic portfolio. Course branches preserve full working materials, while `portfolio/` contains only selected presentation-ready work.
